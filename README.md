# HealthCareDashboards

Welcome to my Healthcare Analytics portfolio! This repository contains my practice projects focused on analyzing, transforming, and visualizing healthcare data using:

Excel – Data cleaning, pivot tables, trend analysis

Power Query – Data preparation and automation

Power BI – Interactive dashboards and performance monitoring

Tableau – Advanced visual storytelling and healthcare KPIs

SQL – Data extraction, transformation, and querying for insights


The projects here are designed to explore real-world healthcare scenarios, such as:

1. Immunization coverage tracking

2. Patient outcomes and hospital performance

3. Resource utilization and capacity planning

4. Claims and billing analysis

5. Public health trends

# Purpose

This repo showcases my journey in healthcare analytics—from raw data to meaningful insights. It’s also a space for experimenting with different BI tools and SQL queries to solve domain-specific problems.

I’ll be regularly updating this repository with new projects, improved dashboards, and optimized SQL queries. Contributions, suggestions, and feedback are always welcome!
